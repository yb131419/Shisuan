🔄 同步價目表書籤

請用電腦的 Chrome / Edge / Safari 開啟這個檔案。

同步價目表

👆 按住這個綠色按鈕，拖到瀏覽器上方的書籤列放開

看不到書籤列？
  1. Chrome / Edge：按 Ctrl + Shift + B（Mac：⌘ + Shift + B）顯示書籤列，再拖一次。
  2. 或按下方按鈕複製程式碼 → 新增書籤 → 名稱填「同步價目表」、網址貼上。
使用方式
  1. 登入康園官網，打開任一商品分類頁。
  2. 點書籤列的「同步價目表」。
  3. 在差異確認頁按「確認寫入」。
請勿分享這個檔案
裡面含有寫入價目表的密鑰。若不小心外流，請在 GAS 執行 resetPriceSyncKey 換新密鑰，並重新產生書籤。
